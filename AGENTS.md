# Repository instructions

For every npm release, package metadata change, or publication workflow change, read and follow `.agents/skills/publish-private-npm/SKILL.md` and its references step by step. Preserve the package's existing npm visibility. Stable releases use the committed package and lockfile version; unchanged versions receive an automatic committed patch release on `main`.

Before changing Convex component code, read the repository Convex guidelines when available. Never expose credentials in source, logs, or chat.
